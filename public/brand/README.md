# public/brand

Copied from what `yantrik-os/brand/render.py` writes (run there: `python3 brand/render.py`).
Nothing here is drawn by hand. To change the mark, change `yantrik-os/brand/build.py`, render,
and copy the outputs here:

| here | from yantrik-os/brand/ |
|---|---|
| yantrik-mark.svg, yantrik-emblem.svg, yantrik-icon.svg, yantrik-name.svg, yantrik-wordmark.svg, yantrik-lockup-stacked.svg | the same names |
| yantrik-mark.ico | yantrik-mark.ico |
| yantrik-mark-{16..1024}.png | yantrik-icon-{16..1024}.png |
| apple-icon-180.png, og-image-1200x630.png, social-preview-1280x640.png, github-avatar-512.png | the same names |

`src/app/icon.svg`, `favicon.ico`, `apple-icon.png`, `opengraph-image.png` and
`twitter-image.png` are copies of yantrik-mark.svg, yantrik-mark.ico, apple-icon-180.png and
og-image-1200x630.png (twice).
